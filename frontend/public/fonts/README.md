# Chart typography

MuseJazzText.otf is the unmodified MuseScore font by Abraham Lee, under SIL OFL 1.1 (see OFL.txt).

Source: https://github.com/musescore/MuseScore/tree/a9adc1bba915324050950ab023607e64589b053e/fonts/musejazz

SHA256: fd465faeb8df396327ad6d1f30d4deca1a0b079db757617d207aa61b85e7c3a7

MulecJazz.ttf is an OFL-licensed derivative: cubic outlines converted to quadratic outlines for ReportLab, plus a Unicode major-chord triangle. It has been renamed to respect the reserved name. Rebuild with `scripts/build_chart_font.py` and fontTools 4.68.0. Both browser and PDF use this same local font, without a runtime download.

This is a handwritten jazz alternative to the Inkpen2 fonts in the supplied reference, not an identical typeface. No fonts have been extracted from the reference PDF.
